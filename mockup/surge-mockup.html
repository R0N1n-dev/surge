Surge

A power-user download manager for Android — YouTube, Instagram, torrents, magnets, plain HTTP and MP3 conversion in one queue. Vue 3 + Vite + Capacitor on the front, a bundled segmented HTTP / yt-dlp / ffmpeg toolchain underneath.

14 screens 9 palettes × light/dark = 18 token sets 120 hand-drawn icons 468 WCAG contrast checks passing minSdk 24 · targetSdk 35 · JDK 21

The app

Every frame below is rendered with the real component CSS and the real generated design tokens — the same files the app imports. Colours, spacing, radii and type are not approximations.

Colour system

The nine palettes from your brief, each expanded through an OKLCH tonal-palette engine into a complete Material-3 style token set for both light and dark. Dual themes follow the 80/20 split; triple themes follow 60/30/10. Neutrals are hue-tinted from the primary so surfaces feel branded rather than generic grey.

Design principles

Glanceable state

Every row carries a 3 px state spine, a monospace tabular readout and a striped progress fill while bytes are actually moving. You can tell what is downloading, stalled, seeding or failed from across the room.

48 dp minimum

Icon buttons are 40 dp visually but extend their hit area to 48 dp. No mis-taps on a moving bus, no "tiny close button" rage.

Progress is honest

Segment ticks show how aria2 is slicing the file. Indeterminate states stay indeterminate — never a fake percentage creeping to 99%.

Progressive disclosure

One primary action per screen (the FAB). Everything else lives in a chip rail, a bottom sheet or an overflow menu — dense without being busy.

Token-driven theming

Zero hard-coded colours in components. Swap the palette or the mode and all 18 combinations stay WCAG AA compliant, verified in CI.

Motion with meaning

220 ms standard easing for state changes, 340 ms emphasized for things entering the screen, spring only on switches. Everything honours prefers-reduced-motion.

Reversible by default

Deletes go to a snackbar with Undo first. Destructive confirmations are reserved for things that actually cannot be undone.

Calm by default

No dark patterns, no auto-play, no badge spam. Notification channels are granular so you can silence progress and keep completions.

Under the hood

The native layer does the heavy lifting so the WebView only ever draws UI and receives events.
